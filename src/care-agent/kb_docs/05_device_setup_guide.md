# Better2gether Device Setup & Wear Guide

## Models
- **B2G Pulse** — entry model. HR, steps, battery. Pairs with the Basic plan.
- **B2G Pulse Pro** — adds SpO2 and skin-temperature sensors. Pairs with Plus plan.
- **B2G Vital** — full sensor suite incl. continuous SpO2 and GPS. Pairs with Premium plan.

## First-time setup
1. Charge to 100% before first use.
2. Install the Better2gether app and create/enroll a member profile.
3. Pair via app → Devices → Add device (see Connectivity SOP TS-01 if pairing fails).
4. Complete the wellness onboarding questionnaire so baselines are personalized.

## Wearing the watch for accurate readings
- Wear snugly, one finger-width above the wrist bone.
- A loose band is the #1 cause of false **SPO2-LOW** and erratic HR readings.
- For sleep tracking, keep the band on but not tight enough to leave a mark.

## Charging
- Full charge lasts ~5 days on B2G Pulse, ~3 days on B2G Vital (GPS/continuous SpO2 use more).
- Charge before it hits 15% to avoid **BATT-LOW** data gaps.
- Unusually fast drain? See Connectivity SOP TS-04.

## Cleaning & care
- Rinse with fresh water after sweat/swim; avoid soaps on the sensor window.
- A dirty sensor window degrades SpO2 and skin-temp accuracy.
